About the Book App Project

This is a React-based Book Management Application that allows users to browse, search, and explore books across different categories.
The application provides category-wise book listing along with a search feature to quickly find specific books.

Users can view detailed information about each book on a separate page and add new books using a dedicated form. 
React Router is used for smooth navigation between pages, and a custom 404 page is implemented to handle invalid routes.

This project demonstrates core React concepts such as component-based architecture, routing, state handling, and clean UI design, making it a 
practical example of a real-world React application.
